## Introduction to Loop Message

You can send messages using "Loop Message" to WhatsApp groups or to personal phone numbers

> **Tip**: Example use cases for "Loop Message"

1.  Every 1st of the month at 9:00 AM, send a reminder in the WhatsApp group to make a personal purchase of RM100 so membership is not terminated
    
2.  Every Monday & Wednesday at 10:30 AM, send the Morning Meeting Zoom link
    

> **Tip**: FYI. "Evergreen Campaign" is for sending different sequential messages. Meanwhile, "Loop Message" sends the same recurring message

## Prerequisites

-   An active Wajom account
-   A WhatsApp number connected to Wajom
-   A created list (can be an empty list initially)
-   Pre-planned message content

## Tips and Best Practices

### ✅ Do’s

-   Ensure the list is created before configuring Loop Message
-   Use descriptive list names (e.g., “LM Prospect Pool”, “LM Follow Up”)
-   Test with a single group first before adding many contacts
-   Ensure Loop Active is enabled before adding contacts
-   Check the Queue regularly to monitor delivery status

### ❌ Don’ts

-   Do not add contacts before finishing the Loop Message setup
-   Do not delete the Waiting Queue (messages will not be sent)
-   Do not schedule too many messages in a single day (risk of account ban)
-   Do not forget to activate Loop Message after completing setup

## Difference: Loop Message vs. Evergreen Campaign

| **Loop Message** | **Evergreen Campaign** |
| --- | --- |
| Sends the **same** message repeatedly | Sends **different sequential** messages |
| Scheduled by calendar (Every Day/Week/Month) | Scheduled by delay (Day 1, Day 2, etc.) |
| For recurring reminders and announcements | For lead nurturing and follow-up sequences |
| All contacts receive the exact same message | Contacts receive messages according to their personal journey |
