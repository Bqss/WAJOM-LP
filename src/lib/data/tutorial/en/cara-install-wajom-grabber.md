## Introduction to Wajom Contact Grabber

Wajom Contact Grabber is a Chrome extension that allows you to extract phone numbers from WhatsApp groups easily and securely. This extension serves as a tool to:

-   **Build a Database**: Collect phone numbers for marketing campaigns
-   **Contact Management**: Extract numbers from multiple groups simultaneously
-   **Export to CSV**: Save data in CSV format to import into Wajom
-   **Seamless Integration**: Directly integrate with the Wajom system

## Prerequisites

Before installing Wajom Contact Grabber, make sure you have:

-   ✅ Google Chrome browser (latest version)
-   ✅ An active Wajom account
-   ✅ A WhatsApp number that has joined the groups
-   ✅ WhatsApp Web access

## Frequently Asked Questions (FAQ)

**Q: How many groups can be grabbed at once?** A: You can check multiple groups and export all of them into a single CSV file.

**Q: Is it safe to use this extension?** A: Yes, this extension is designed specifically for Wajom users and does not store your personal data.

**Q: Why doesn't the extension appear after installation?** A: Make sure you select the “dist” folder and not the root “wajom-grab” folder. Refresh the WhatsApp Web page if needed.

**Q: Can it be used on browsers other than Chrome?** A: Currently, Wajom Contact Grabber only supports Google Chrome.
