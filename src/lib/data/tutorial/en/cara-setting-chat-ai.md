## Introduction to Wajom AI Chat

Wajom AI Chat is designed to automatically respond to prospect inquiries with a human-like touch.

## Chat AI Setup Guide

Chat AI will answer questions asked by prospects. Chat AI responses depend on the “Training Data” script.

The Chat AI reply style depends on the “AI Behavior” script & Wajom Chat AI settings.

Chat AI can read images, videos, PDFs, and voice notes from prospects (requires toggling on during setup).

AI token costs are deducted each time Chat AI provides an answer.

Chat AI will stop responding when AI tokens run out.

> **Alert**: Alert! Wajom Chat AI is designed not to look like a robot. Equipped with “Fallback Delivery Warning” and “Human Takeover”.

Built to save AI token costs – “Ignore keyword”, “Pause & Resume” keywords, and many other cost-saving settings.

27. “Chatbot Limit”: The time given for the AI to wait and collect multiple messages before sending a response.

This helps prevent spam when a user sends short messages in quick succession, such as “okay” and “thank you”.

With this feature, the AI combines these messages into a single response like “okay, thank you”, keeping the chat interface clean and uncluttered.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-09-10/a5246001-a4b8-4b51-8c71-1d9d6a6d8bb8/user_cropped_screenshot.webp?tl_px=0,121&br_px=1352,876&force_format=jpeg&q=100&width=1120.0)

28. “Content Length”: The number of previous messages you want the AI to retain in memory.

For example, if you set “Content Length” to 10, the AI will store the last 10 messages and read them back to answer the prospect's question.

The higher the number, the more AI tokens are consumed because the AI must store and recall more message context.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-09-10/5099597d-ab5a-4b53-9df1-f10b96800121/user_cropped_screenshot.webp?tl_px=0,95&br_px=1352,851&force_format=jpeg&q=100&width=1120.0)

29. “Response Length Character”: Determines how many characters are allowed per message.

For scannable copywriting, keep it to 3 lines per paragraph.

3 lines of text is typically around 150 characters.

92. “Delay Per Message”: The time delay between sending each message bubble.

Example: If you set delay = 5 seconds and Chat AI has 4 message bubbles to send, the total delivery time will be 5 seconds x 5 message bubbles = 25 seconds to deliver all messages.

Do not set it to 1 second as it feels too fast. Set it to more than 3 seconds so it looks like a real person typing.
