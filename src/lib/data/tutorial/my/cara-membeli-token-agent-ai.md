Agent AI menggunakan kuota token untuk membaca mesej pelanggan, menganalisis basis pengetahuan (_knowledge base_), dan menghasilkan balasan otomatis di WhatsApp. Setiap kali Agent AI membalas, saldo token akun anda akan terpotong sesuai panjang teks dan tingkat ketelitian AI yang dipilih. Ketika saldo token habis, Agent AI akan berhenti membalas secara otomatis.

Panduan ini menjelaskan cara memeriksa saldo token di dashboard Agent AI, memilih paket token yang tepat, serta menyelesaikan proses pembelian token.

## Prasyarat

✅ Akun Wajom anda sudah login di portal resmi `portal.wajom.co`.

✅ nombor WhatsApp bisnis anda sudah terhubung (_Connected_).

✅ Metode pembayaran (QRIS, Virtual Account, atau E-Wallet) siap digunakan.

---

## 1. Memeriksa Sisa Saldo Token Agent AI

1.  Buka portal Wajom di [portal.wajom.co](https://portal.wajom.co).
2.  Pilih instance WhatsApp anda, lalu buka menu **Agent AI** > tab **Ringkasan**.
3.  Di samping kartu toggle switch status, perhatikan kartu **Saldo token AI**.
4.  Di dalam kartu tersebut tercantum total kuota token aktif anda beserta tautan **Isi ulang saldo**.

![Kartu Saldo Token AI di Tab Ringkasan](/images/agent-ai/beli-token-01-saldo.png)

> **Tip**: Kami menyarankan untuk melakukan pengisian ulang saldo saat sisa token berada di bawah 100.000 token agar Agent AI tidak berhenti mendadak saat melayani pelanggan. anda juga dapat menghidupkan peringatan otomatis saat saldo menipis melalui menu [Settings](/agent-ai/cara-mengaktifkan#9-menetapkan-mesej-cadangan-dan-notifikasi-admin).

---

## 2. Membuka Halaman Pembelian Token

1.  Klik tautan teks biru **Isi ulang saldo** yang ada pada kartu Saldo token AI di tab **Ringkasan**.
2.  anda akan diarahkan ke halaman checkout token resmi di `/checkout-token`.
3.  Pada halaman ini, sistem menampilkan informasi saldo token anda saat ini dan katalog paket token resmi Wajom.

---

## 3. Memilih Paket Token yang Sesuai

Di ruangan **Pilih Paket Token**, pilih paket yang paling efisien untuk volume mesej masuk bisnis anda:

![Daftar Paket Token di Halaman Checkout](/images/agent-ai/beli-token-02-paket.png)

| Paket Token | Jumlah Token | Harga Promo | Estimasi Penggunaan | Rekomendasi Bisnis |
| --- | --- | --- | --- | --- |
| **STARTER 1M** | 1.000.000 tokens | Rp39.000 | ± 1.500 – 2.500 balasan | UKM atau bisnis yang baru mulai menguji bot. |
| **ADVANCE 2M** | 2.000.000 tokens | Rp66.000 | ± 3.000 – 5.000 balasan | UKM yang sudah berkembang dengan sembang reguler. |
| **GROWTH 3M** | 3.000.000 tokens | Rp99.000 | ± 5.000 – 8.000 balasan | Bisnis menengah dengan trafik CS yang meningkat. |
| **PRO 10M** | 10.000.000 tokens | Rp299.000 | ± 15.000 – 25.000 balasan | **Best Seller:** Bisnis dengan volume interaksi tinggi. |
| **ENTERPRISE 40M** | 40.000.000 tokens | Rp999.000 | ± 60.000 – 100.000 balasan | Skala besar, toko ritel besar, dan kampanye promosi. |

1. Tentukan paket token yang anda inginkan. 2. Klik butang **Pilih** pada kartu paket tersebut. Kartu yang dipilih akan otomatis diberi sorotan biru.

---

## 4. Menyelesaikan Pembayaran

1.  Perhatikan ruangan sebelah kanan pada bagian **Ringkasan Pesanan**.
2.  Pastikan nama paket yang dipilih, jumlah token, dan nominal tagihan sudah sesuai.
3.  Pilih metode pembayaran instan:
4.  - **QRIS**: Pembayaran instan melalui GoPay, OVO, Dana, ShopeePay, atau BCA Mobile.
5.  - **Virtual Account (VA)**: Transfer bank otomatis melalui BCA, Mandiri, BNI, BRI, atau Permata.
6.  - **E-Wallet**: Sesuai channel pembayaran yang aktif.
7.  Klik butang **Bayar Sekarang** untuk memunculkan kode QRIS atau nombor Virtual Account.
8.  Selesaikan pembayaran sebelum batas waktu tagihan berakhir.

![Panel Ringkasan Pesanan Pembelian Token](/images/agent-ai/beli-token-03-checkout.png)

---

## 5. Verifikasi Penambahan Saldo Token

selepas pembayaran berhasil diselesaikan: 1. Kembali ke halaman [Ringkasan Agent AI](/agent-ai/index). 2. Periksa angka pada kartu **Saldo token AI**. Jumlah saldo akan otomatis bertambah secara _real-time_ tanpa perlu _refresh_ manual. 3. Agent AI anda langsung siap melanjutkan merespons perbualan pelanggan tanpa hambatan.
