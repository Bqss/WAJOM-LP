## Introduction to Wajom Campaigns

Campaigns are a feature used to send messages to thousands of WhatsApp numbers automatically and in a controlled manner. This feature allows you to:

-   **Broadcast Messages**: Send text, images, videos, PDFs, and audio
-   **Target Audience**: Select specific lists or groups for the campaign
-   **Anti-Banned Protection**: Use the batch system and delays for account safety
-   **Follow Up**: Track delivery statuses and create follow-up campaigns

## Difference Between Campaign vs. Evergreen Campaign

| **Campaign** | **Evergreen Campaign** |
| --- | --- |
| Sends a message only once | Sends a series of messages (over multiple days) |
| For announcements or promotions | For nurturing and follow-ups |
| Set up once, run once | Set up once, runs continuously |

## Prerequisites

-   An active Wajom account
-   A connected WhatsApp number
-   A prepared contact list (Tutorial 10)
-   Pre-planned message content

### Step 2: Campaign Configuration

5. **Campaign Type**:

Personal - To send the campaign to personal numbers. Only numbers added to the "List" will receive the message

Group - To send the campaign into WhatsApp groups. All group members will see the message in the WhatsApp group

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-09-12/ce0582e3-e724-4c94-81b7-a26322afea81/user_cropped_screenshot.webp?tl_px=0,95&br_px=1352,851&force_format=jpeg&q=100&width=1120.0)

6. Title - Field to write a title for the campaign we are going to run

For internal use only. The "Title" will not appear in the message sent to prospects

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-09-12/77f5bb43-84b8-4a27-aa86-089457ac4f94/user_cropped_screenshot.webp?tl_px=0,0&br_px=1352,947&force_format=jpeg&q=100&width=1120.0)

7. “Send To” Who should this campaign be sent to? We can choose to send it to “Lists” or a Campaign

The "Lists" contain the phone numbers we have imported. Refer to Tutorial 10 on how to add phone numbers into a Wajom "List"

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-09-14/8a6e7619-21fd-4118-9fa0-5237acca8b96/user_cropped_screenshot.webp?tl_px=0,50&br_px=1352,806&force_format=jpeg&q=100&width=1120.0)

8. Send To Campaign - Can only be selected after you have successfully run at least one campaign

FYI For all campaigns we have run, we can check the message delivery status for every single prospect's number

We can choose to Follow UP only prospects who have Read @ Sent @ All Queue

“Filter by Queue Status”

All Queue - All numbers available in the "Lists". This means even if the prospect hasn't read or hasn't been sent the message, the Follow UP message will still be sent immediately

Sent - Send the campaign to numbers that have successfully received the message.

Read - Only send the campaign to those who have read our message. Those who haven't read will not receive the message

### Step 4: Anti-Banned Protection

11. **Contact per batch: 25 numbers | Interval per batch: 60 minutes**

This means that after the Wajom system sends the campaign to 25 phone numbers, it will rest for 60 minutes (1 hour)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-09-16/3267c06d-103a-4a9a-895e-b7dc5e66a047/user_cropped_screenshot.webp?tl_px=0,95&br_px=1352,851&force_format=jpeg&q=100&width=1120.0)

> **Alert**: Alert! For new numbers, run only 10 numbers per day. You can gradually increase the volume of numbers sent. If you receive a warning that your phone number might get banned, stop running the campaign immediately & reduce the number of messages sent

## Tips and Best Practices

### ✅ Do’s

-   Use Batch Campaign to prevent bans
-   Set an appropriate delay time (10-15 minutes between contacts)
-   Test with a small batch of numbers before launching a large campaign
-   Use Spintext for copywriting variations
-   Monitor campaign statuses in Queue Management

### ❌ Don’ts

-   Do not send too many messages at once from a new number
-   Do not skip the batch campaign settings
-   Do not use spammy or irrelevant content
-   Do not ignore warnings from WhatsApp
